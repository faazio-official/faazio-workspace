# Global Data Store & Mock Databases

This directory is designated for all static datasets, mocks, configurations, and core assets used dynamically across different sub-applications.

## 📦 Directory Structure
- `exploreData.ts`: Holds categories, banners, and explore widgets for the main SuperApp Hub.
- `mockProducts.ts`: Holds centralized database arrays for Food (Food), FA Mart, Grocery, and Fa Pharma products.

## 📐 Standards
- **Strict Typing**: All data exports should be fully typed (e.g., using types from `@/types.ts` or local schemas).
- **Asset Integrity**: Only high-resolution, reliable Unsplash image URLs are allowed to keep the visual aesthetics elegant.
