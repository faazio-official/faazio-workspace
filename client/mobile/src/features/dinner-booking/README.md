# Dinner Booking Module (Table Reservation)

This directory handles gourmet table reservations, schedule selections, and guest counts.

## 📁 Key Files
- `DinnerBookingScreen.tsx`: Vetted fine-dining kitchen partners list and overlay form.

## 🛠️ Implementation Standards
- **Zero-Cart Requirement**: Table reservations do not require a shopping cart or payment credentials.
- **Micro-feedback**: Employs interactive guest sliders and confirmation badges.
