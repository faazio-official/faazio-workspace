# Home Module

This directory handles the central dashboard hub experience of the Faazio SuperApp.

## 📁 Key Files
- `HomeScreen.tsx`: Core landing page showing current active status, consolidated service options, and quick-access utility grids.

## 🛠️ Implementation Standards
- **Grid Layout**: Displays cards for the 4 core services (FA Mart, Faazio Food, FA Grocery, FA Pharma).
- **Consolidated Analytics**: Shows consolidated statuses such as delivery statuses and help tickers.
