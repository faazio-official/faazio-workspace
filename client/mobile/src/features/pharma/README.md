# Pharma Module

This directory handles pharmacy catalogs, prescription uploads, and secure health compliance.

## 📁 Key Files
- `PharmaScreen.tsx`: Safe upload component and essential healthcare catalog.
- `blood-donor/`: Blood Donor registration wizard + registered-donor dashboard (see its README).

## 🛠️ Implementation Standards
- **Secure File Storage**: Native camera and gallery configurations proxy uploads directly to encrypted buckets.
- **HIPAA Standards**: Ensures sensitive user medical files are masked in local telemetry logs.
