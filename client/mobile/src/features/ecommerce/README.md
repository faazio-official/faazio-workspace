# E-Commerce Module (Mart)

This directory handles the shopping catalogue, global products listings, and specialized cart addition workflows.

## 📁 Key Files
- `EcommerceScreen.tsx`: Core catalog screen containing category tabs (Apparel, Footwear, accessories) and grid-based trending items.

## 🛠️ Implementation Standards
- **Zustand Synced**: Interacts with the shared cart slice.
- **Micro-interactions**: Incorporates product rating bubbles, category indicators, and optimized quick-add cards.
