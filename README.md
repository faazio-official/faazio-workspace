 # Faazio SuperApp

React Native (Expo) superapp. All active work lives in `client/mobile/`.

## Start

```bash
cd client/mobile
npm install
npm run android   # device/emulator
```

Verify: `npm run ts:check` and `npm run check:boundaries` (run from `client/mobile/`).
