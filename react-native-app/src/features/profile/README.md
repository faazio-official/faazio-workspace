# User Profile Module

This directory handles user account management, delivery configurations, and historic activity records.

## 📁 Key Files
- `ProfileScreen.tsx`: Personal details panel, orders status, and visual setting grids.

## 🛠️ Implementation Standards
- **Unified Summary**: Integrates status trackers summarizing the count of active orders, bookings, and prescription records.
- **Brand Identity**: Features official user details in clear design groups.
