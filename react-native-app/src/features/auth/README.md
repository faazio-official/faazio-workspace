# Auth Module

This directory handles user login, verification OTP, and brand onboarding workflows.

## 📁 Key Files
- `LoginScreen.tsx`: Modern screen featuring secure passwords, email-phone toggles, and Apple/Google sign-in integration.

## 🛠️ Implementation Standards
- **Secured Tokens**: Authorization tokens are persisted using safe storage APIs.
- **Brand Identity**: Strict Faazio brand dots and typography are enforced across all subforms.
